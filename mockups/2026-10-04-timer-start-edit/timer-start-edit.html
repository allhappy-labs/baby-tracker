Home: make "edit start time" of a running timer visible

Today the whole hero is an invisible tap target. It opens the existing Running Timer editor (start time + finished parts), but nothing on screen says so. Each option adds a visible control and keeps tapping the hero as a shortcut. Sample: right breast feeding since 15:09, now 15:11.

Now

"since 15:09" is plain grey text. Tapping anywhere on the hero opens the editor, but nothing hints that it will.

A · Start time becomes a button recommended

"since 15:09" turns into a tinted pill: Started 15:09 ✎. The control sits on the value it changes, in the timer's colour. No new row; it works the same for feed and sleep.

B · Pencil next to the timer

A small round ✎ button beside the big number. Clearly reads as "edit", but it pulls the 68pt number off-centre, and "edit what?" is less obvious than A.

C · "Start" button in the dock

A clock button joins Stop / diaper / more. Right where the thumb is, but the dock is for logging actions, and it adds a third small button to a tight row.

D · Quick nudge chips

The most common fix is "I tapped Start late." Chips move the start back by one tap (−1m/−5m/−10m) and ✎ opens the full editor. Fastest, but easy to mis-tap, so it needs Undo.

A · tapping the pill

Opens the existing editor. Option: add the same −1/−5/−10 chips above the time wheel, which gives D's speed without risking a mis-tap on Home.
