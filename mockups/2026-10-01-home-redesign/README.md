# Home + tracking redesign mockups (2026-10-01)

Approved during brainstorming for `docs/superpowers/specs/2026-10-01-home-tracking-redesign-design.md`.
Open the HTML files in a browser. The spec wins if a mockup disagrees with it.

- `home-layout.html` — **C · Glance + dock** chosen (A and B rejected).
- `icons-v3.html` — **A (line style)** and **diaper 1** chosen. Its Vitamin D dropper is superseded by `supplement-icon.html`.
- `supplement-icon.html` — **2 (capsule + drop)** chosen for Meds.
- `flow-start-stop.html` — the start → stop model: one timer per part, automatic joining within the break limit.
- `sheets-v2.html` — Diaper, Bottle, Bottle → Stop and More (···) sheets. The diaper option reads **Mixed**.

The running-state mockup with Switch/Pause (`running.html`) was rejected in favour of start → stop and is not kept.
