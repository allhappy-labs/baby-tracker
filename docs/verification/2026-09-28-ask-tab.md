# Native Ask tab verification — 2026-09-28

## Scope

The `feat/ask-foundation-models` branch adds an Ask tab between History and Insights. It uses Apple's on-device `SystemLanguageModel` to interpret questions and select fact IDs. Swift reads the current child-scoped log, computes totals, validates selected IDs, and renders all displayed values. Chat files live in the app's private Application Support directory, outside the App Group, sync protocol, export, and widgets. They are excluded from backup and use iOS file protection.

One conversation is stored per installation identity and child. New Chat deletes only the current conversation after confirmation; a generation token prevents an older response from recreating it. Local conversations move to the first account used on this installation for all children in the local realm. A separate local identity after account use prevents an interrupted migration from showing the old transcript on sign-out; only the first account can retry that migration. Later signed-out local chats are not moved into a different account. Confirmed account deletion removes that account's chat, and confirmed or synced child tombstones remove all identity-scoped chats for the child. Ordinary realm switches do not delete conversations.

## Limits and decisions

- Model-generated free prose is not displayed. The model selects known fact IDs; Swift renders a neutral introduction, all computed aggregate facts, selected details, and source controls. This prevents an unverified sentence from adding a numeric, medical, or qualitative claim. The handoff is therefore concise and factual rather than a polished narrative.
- `SystemLanguageModel.tokenCount(for:)` is available only on iOS 26.4 and later in the installed SDK. On the deployment floor of 26.0 through 26.3, the adapter reduces the prompt by a conservative character cap while preserving fact boundaries and prioritizing totals. Actual model behavior on those OS versions remains unverified.
- New Ask copy has English source text and Ukrainian translations. The app's other supported languages currently fall back to English in Ask.
- Simulator tests do not prove Apple Intelligence availability, actual answer quality, or absence of runtime model traffic on a physical device. `xcrun devicectl list devices` showed paired physical iPhones, but this task did not install a test build or introduce fixture data into a personal device.
- Two earlier UI runs exposed test-only issues: Settings audit findings vary for offscreen labels, and immediate breast-timer stops create no persisted feed because the store discards intervals under 30 seconds. The audit expectation and test timing were corrected. A later simulator launch inherited a running feed from an interrupted runner; uninstalling only the dedicated simulator's test app cleared the fixture. The final uninterrupted 87-case run passed.
