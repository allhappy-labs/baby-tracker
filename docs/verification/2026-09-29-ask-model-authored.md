# Model-authored Ask answers, 2026-09-29

The prior Ask revision returned an app-written sentence for recognized bottle-volume questions and synthesized canned answers when model output failed validation. This revision removes both paths. The selected child's bounded local log query and exact Swift aggregates remain available as facts; Foundation Models writes the answer. The app substitutes explicit fact placeholders or checks a model-written bottle total and period against the queried log. An incorrect total is rejected. If the model cannot produce a grounded answer after three attempts, Ask keeps the question in the composer and shows a retry error instead of saving an app-written answer.

Verification: new tests first reproduced the canned handoff substitution and synthesized answer on invalid output. After the change, focused tests passed for model wording preservation, exact 170 ml acceptance, incorrect 260 ml rejection, an empty-log answer that does not claim zero intake, and restoration of an ungrounded question. The full Swift package gate passed 947 tests, and an unsigned generic iOS Simulator build passed. An opt-in local Foundation Models run against synthetic feed entries produced a validated 170 ml answer after rejecting incorrect attempts; a second run passed. These synthetic macOS checks do not establish answer quality on a physical iPhone or every free-form question.
