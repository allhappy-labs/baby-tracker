# Pumping Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A parent times a pumping session (Left / Right / Both), stops it, gives it an amount, and sees it on every baby's Home, History and Ask on both phones, while a bottle or sleep timer runs alongside, untouched.

**Architecture:** One new synced kind, `pump`, owned by the family: it has no baby. On the server it is care kind 10 in the existing `care_entities` table with `baby_id` NULL, added by migration `000034`; the write path allows one running pump per family and a partial unique index backs it. On the phone it is a SwiftData `PumpEntry` in `SchemaV12`, a `HistoryItem` case that every baby's reads merge in, and a Home action `pump` in the arrangeable order. A running pump is an ordinary entry with no end, never an `ActiveTimer`; Home draws it as its own strip and the starting phone shows its own Live Activity.

**Tech Stack:** Go server on PostgreSQL 17 (`Server/`), Swift 6 / SwiftUI (iOS 26) / SwiftData package (`Packages/BabyTracker`), Swift Testing, ActivityKit, App Intents, XCUITest.

**Spec:** `docs/superpowers/specs/2026-10-09-pumping-design.md` (with its Revision 2026-10-12 note). Read it first; this plan argues from it.

**Base:** `main` at `7f9ff2f0` (schema 33, `SchemaV11`, `EXPECTED_TESTS := 1856`). The fresh precedent for a new synced kind is immunizations: `docs/superpowers/plans/2026-10-11-immunizations.md` and commits `fa87e48d`, `6fc619f1`, `cf95005d`, `6d54b2b2`, `17f8b95a`, `f95646b6`, `8da6365d`, `13e76a18`, `a46805cb`, `50bf962e`, `29a959bc`, `1edf2b8c`, `abbf72f4`, `339f655f`. ## Global Constraints

- Wire shape, never changed once shipped: entity kind `pump`, payload version 1, payload keys exactly `started_at`, `ended_at`, `time_zone_id`, `side`, `volume_ml`, `note`. `ended_at`, `volume_ml` and `note` are always present and may be `null`. There is never a `baby_id`. A pump's delete payload is `{}`. The server refuses unknown keys.
- Server care kind code: `10`. Migration: `Server/migrations/000034_pumping.sql`. Compatibility window: `min 34, max 34`.
- Validation, on the server and mirrored on the phone: `side` is `left`, `right` or `both`; `volume_ml` is 0–1000 with at most 2 decimals; `ended_at` is not before `started_at` and at most 6 hours after it; `started_at` and `ended_at` are not later than the accept time plus 1 minute (the grace `care/timers.go` gives a timer edit).
- One running pump per family: the losing open start gets `status: "superseded", code: "pump_running"` with the running pump as `canonical_entity`. An update that clears the end of a finished pump is `rejected` / `pump_reopened`.
- Phone schema: `SchemaV12` = `SchemaV11.models + [PumpEntry.self]`, one lightweight stage V11→V12. `SchemaV11` is not edited beyond its doc comment. A V11 store opens in place.
- `PumpEntry` conforms to `ChangeLoggable`, `Touchable` and `RealmScoped`. It must **not** conform to `BabyOwnedRecord`.
- Unchanged: feed and sleep timer behaviour, `ActiveTimer`, `TimerActivityAttributes`, `TimerKind`, the feed Live Activity, `PartKind`, `PartFormModel`. Insights shows no pumps.
- Home action raw value: `pump`, appended last in `HomeActionKind`, after `vaccine`. Never rename it. It is not a timed action in `HomeLayout`: it stays available while a feed or a sleep runs. Accessibility identifiers follow from it: `home.pump`, `more.pump`, `homeButtons.row.pump`. Panel prefix `pump` (`pump.side`, `pump.startNow`, `pump.editRunning`, `pump.start`, `pump.end`, `pump.amount`, `pump.addAmount`, `pump.removeAmount`, `pump.details`, `pump.note`, `pump.validation`, `pump.save`, `pump.delete`, `pump.confirmDelete`); How much? prefix `pumpAmount` (`pumpAmount.caption`, `pumpAmount.volume`, `pumpAmount.save`, `pumpAmount.skip`); the strip `home.pumpStrip`, `home.pumpOpen`, `home.pumpStop`. ## Review Focus

The five ways this is most likely to hurt a real family. The test that pins each is in the task named.

1. **Both phones start a pump while one is offline.** After sync there is exactly one running pump. If the losing phone has already stopped its session, the session still reaches the family as a finished entry; if it is still running, it gives way to the winner. Tests in Task 3 (`TestSecondOpenPumpIsSupersededAndAFinishedOneIsNot`, `TestTwoOpenStartsInOneBatchKeepOne`) and Task 5 (`aLosingStartAlreadyStoppedIsSentAgainFinished`, `aLosingStartStillRunningGivesWayToTheWinner`).
2. **A pump is forgotten and stopped 7 hours later** (strip, panel or Lock Screen). It saves ending exactly 6 h after its start and is never refused by the server. Tests in Task 6 (`stoppingPastSixHoursEndsAtTheCap`) and Task 12 (`stoppingFromTheCardAsksForTheAmountNextOpen`).
3. **An ounces user enters 3 oz.** The amount is stored as 88.72 ml, two decimals, so the server accepts it; a third decimal is refused by the server. Tests in Task 6 (`anOunceAmountIsStoredToTwoDecimals`) and Task 2 (`TestPumpValidation`, "three places").
4. **The owner logged pumps before creating the family.** They reach the caregiver. The import manifest, which keys records by baby, neither drops them nor gets them refused. Tests in Task 5 (`importSendsPumpsAsPlainCreates`) and Task 14 (the E2E's first step).
5. **The other phone stops or deletes the session, the start loses the race, or it passes 6 h.** This phone's Lock Screen card ends at the next store change or app activation and never shows a running clock for a session that is over. Tests in Task 12 (`aCardWhosePumpEndedElsewhereEnds`, `aCardWhoseStartLostTheRaceEnds`, `aCardPastTheSixHourCapEnds`).

## Design decision: a pump is a care row without a baby

`care_entities.baby_id` is already nullable: the baseline's shape check says `(kind = 1) = (baby_id IS NULL)`, so today only a baby row has none, and `care_entities_baby_fk` (MATCH SIMPLE) is not checked for a NULL. Letting kind 10 have none too is one clause of one CHECK. Every reader was audited at the base:

| Reader | How it selects | A pump (`baby_id` NULL) |
|---|---|---|
| `care.cascadeTargets`, `sqlFetchCascadeTargets` | `baby_id = ANY(...)`, `r.BabyID != nil && *r.BabyID == baby` | never a cascade target: a baby delete leaves it |
| `care.applyRecord` parent check | `mutationBabyID(m)` then a baby lookup | must skip `pump` (Task 3) |
| `familyread` (MCP history and summary) | `baby_id=$2` and a fixed kind map | never read; MCP unchanged |
| `liveactivity/snapshot.go` | `baby_id=$2 AND kind=…` | never read |
| `app.live_activity_mark_dirty` (baseline) | joins babies by `kind=1` | a pump write marks the family dirty, as any write does; cards recompute unchanged |
| `sync` snapshot and pull, `care.Stream` | `(kind, id)` and `changed_seq` | served; kind 10 pages last |
| `export` | `care.Stream`, then a switch on kind | needs a `pumps` section (Task 3) |
| `importer` | manifests keyed by `local_baby_id`; kind allowlist | never sees one; the phone sends pumps as plain creates (Task 5) |
| quota counters | `Row.CountsAsRecord`: live and not baby or timer | counts as a record |
| purge function (baseline :1085) | deletes `kind > 1`, then `kind = 1` | deleted with the family's other records |

The alternative, a table of its own, would need its own sequence, receipts, snapshot paging, export and counters: everything `care_entities` exists to share.

- [ ] **Step 1: Write the migration** — `Server/migrations/000034_pumping.sql`

The `care_entities_kind_shape` expression is `000033_immunizations.sql`'s with three changes: `(kind = 1) = (baby_id IS NULL)` becomes `(kind = ANY (ARRAY[1, 10])) = (baby_id IS NULL)`; the started-at array gains `10`; the ended-at array gains `10`.

```sql
-- 000034_pumping: care kind 10, pump. A pumping session belongs to the
-- family, not a baby: baby_id is NULL, as it is for a baby row, so the
-- baby-delete cascade and every per-baby read never see it. started_at and
-- ended_at are typed; the side, the amount and the note live in wire. A
-- family has at most one pump still running. No table, policy or grant changes.
ALTER TABLE public.care_entities DROP CONSTRAINT care_entities_kind_check;
ALTER TABLE public.care_entities ADD CONSTRAINT care_entities_kind_check CHECK (((kind >= 1) AND (kind <= 10)));

ALTER TABLE public.care_entities DROP CONSTRAINT care_entities_kind_shape;
ALTER TABLE public.care_entities ADD CONSTRAINT care_entities_kind_shape CHECK ((((kind = ANY (ARRAY[1, 10])) = (baby_id IS NULL)) AND ((kind = 1) = (sort_order IS NOT NULL)) AND ((kind = 1) = (name_hash IS NOT NULL)) AND ((kind = 5) = (timer_kind IS NOT NULL)) AND ((kind = 6) = (label IS NOT NULL)) AND ((kind = ANY (ARRAY[2, 3, 4, 5, 6, 8, 9, 10])) = (started_at IS NOT NULL)) AND ((ended_at IS NULL) OR (kind = ANY (ARRAY[2, 3, 4, 10]))) AND ((session_id IS NULL) OR (kind = ANY (ARRAY[2, 3, 5]))) AND ((completed_record_id IS NULL) OR ((kind = 5) AND (tombstoned_at IS NOT NULL))) AND ((kind = 2) OR ((breast_seconds = 0) AND (bottle_volume_ml IS NULL) AND (bottle_observations = 0) AND (bottle_missing = 0))) AND ((shortest_part_seconds IS NULL) OR (kind = ANY (ARRAY[2, 5]))) AND ((breast_seconds = 0) OR (shortest_part_seconds IS NOT NULL)) AND ((shortest_part_seconds IS NULL) OR (timer_kind IS DISTINCT FROM 2)) AND ((bottle_volume_ml IS NULL) = (bottle_observations = 0)) AND ((tombstoned_at IS NULL) OR ((breast_seconds = 0) AND (bottle_observations = 0) AND (bottle_missing = 0) AND (shortest_part_seconds IS NULL)))));

-- care_entities_seven_days already holds ended_at at or after started_at.
ALTER TABLE public.care_entities ADD CONSTRAINT care_entities_pump_six_hours
  CHECK (((kind <> 10) OR (ended_at IS NULL) OR (ended_at <= (started_at + '06:00:00'::interval))));

-- The backstop for "one running pump per family", and the index the write
-- path reads the running pump through. The rule itself is decided under the
-- family lock (care.applyRecord), which answers superseded; this makes a
-- missed check an error rather than a second running pump.
CREATE UNIQUE INDEX care_entities_one_open_pump ON public.care_entities USING btree (family_id)
  WHERE ((kind = 10) AND (tombstoned_at IS NULL) AND (ended_at IS NULL));

ALTER TABLE public.sync_page_bindings DROP CONSTRAINT sync_page_bindings_resume_kind_check;
ALTER TABLE public.sync_page_bindings ADD CONSTRAINT sync_page_bindings_resume_kind_check CHECK (((resume_kind >= 1) AND (resume_kind <= 10)));

COMMENT ON COLUMN public.care_entities.kind IS 'care kind: 1 baby, 2 feed, 3 sleep, 4 diaper, 5 timer, 6 supplement, 7 growth_profile, 8 measurement, 9 immunization, 10 pump';
COMMENT ON COLUMN public.sync_page_bindings.resume_kind IS 'care kind: 1 baby, 2 feed, 3 sleep, 4 diaper, 5 timer, 6 supplement, 7 growth_profile, 8 measurement, 9 immunization, 10 pump';

INSERT INTO public.schema_privilege_manifest(schema_version,principal,object_kind,object_identity,privileges)
 SELECT 34,principal,object_kind,object_identity,privileges
 FROM public.schema_privilege_manifest WHERE schema_version=33;
UPDATE public.schema_compatibility SET current_version=34,
 introduced_by='000034_pumping.sql',recorded_at=now() WHERE singleton;
```

`import_record_manifests_entity_kind_check` is left as it is: a pump is never an import record.

The care CHECKs are inherited by the 16 partitions (000033 dropped and re-added them on the parent the same way), a CHECK added to the parent is added to every partition, and `CREATE UNIQUE INDEX` on the partitioned parent builds one index per partition; `family_id` is the partition key, so the unique index is allowed. // validatePumpTimes: a pumping session's end, when it has one, is not before
```go
// its start and at most six hours after it. Whether either is in the future
// needs the accept time, so the record rules check that (applyRecord).
func validatePumpTimes(start string, end *string) error {
	startNormalized, err := protocol.NormalizeTimestamp(start)
	if err != nil {
		return protocol.ErrInvalidTimestamp
	}
	if end == nil {
		return nil
	}
	endNormalized, err := protocol.NormalizeTimestamp(*end)
	if err != nil {
		return protocol.ErrInvalidTimestamp
	}
	startTime, _ := time.Parse("2006-01-02T15:04:05.000000Z", startNormalized)
	endTime, _ := time.Parse("2006-01-02T15:04:05.000000Z", endNormalized)
	if endTime.Before(startTime) || endTime.Sub(startTime) > 6*time.Hour {
		return protocol.ErrInvalidTimestamp
	}
	return nil
}
```

```swift
    /// reached the server. Whatever followed this start (a stop, an amount)
    /// was written against a session the server never kept, so it is
    /// withdrawn, and the running session is shown instead. A session this
    /// phone has already stopped is still a real one, so it goes again as one
    /// create of its finished state, which one-running-per-family lets
    /// through. One still running gives way. Returns the winner, for the
    /// page to rematerialize.
    func settleLosingPumpStart(_ row: SyncOutboxEntry, winner: CanonicalEntity?) throws -> EntityKey? {
        let entityID = row.entityID
        let realmKey = activeRealm.encodedKey
        for later in try liveOutboxRows() where later.entityID == entityID && later.entityKind == .pump && !later.deliveryState.isTerminal {
            later.deliveryState = .superseded
            later.supersededCode = "pump_running"
        }
        var touched: EntityKey?
        if let winner, winner.meta.id != entityID {
            // A later page may already hold a newer state of the winner.
            if winner.meta.entityVersion >= (try observedVersion(of: winner.meta.id, kind: .pump)) {
                try applyCanonical(winner, entityID: winner.meta.id, version: winner.meta.entityVersion)
```

```swift
import Foundation
import SwiftData
import BabyCore

public enum PumpError: Error, Equatable, Sendable {
    /// A pump is already running in this family.
    case alreadyRunning
    /// End before start, longer than six hours, later than now, or a
    /// finished session asked to run again.
    case invalidTimes
    /// Outside 0–1000 ml.
    case invalidVolume
    /// Stop asked of a session that has already ended.
    case notRunning
}

public extension BabyStore {
    func runningPump() throws -> PumpEntry? {
        let key = activeRealm.encodedKey
        var descriptor = FetchDescriptor<PumpEntry>(predicate: #Predicate {
            $0.realmKey == key && !$0.isTombstoned && $0.endedAt == nil
        })
        descriptor.sortBy = [SortDescriptor(\.startedAt, order: .reverse)]
        return try context.fetch(descriptor).first
    }

    func pump(id: UUID) throws -> PumpEntry? {
        let key = activeRealm.encodedKey
        return try context.fetch(FetchDescriptor<PumpEntry>(predicate: #Predicate {
            $0.id == id && $0.realmKey == key && !$0.isTombstoned
        })).first
    }

    func pumps(from start: Date, to end: Date) throws -> [PumpEntry] {
        let key = activeRealm.encodedKey
        var descriptor = FetchDescriptor<PumpEntry>(predicate: #Predicate {
            $0.realmKey == key && !$0.isTombstoned && $0.startedAt >= start && $0.startedAt < end
        })
        descriptor.sortBy = [SortDescriptor(\.startedAt, order: .reverse)]
        return try context.fetch(descriptor)
    }

    func lastFinishedPump() throws -> PumpEntry? {
        let key = activeRealm.encodedKey
        let finished = try context.fetch(FetchDescriptor<PumpEntry>(predicate: #Predicate {
            $0.realmKey == key && !$0.isTombstoned && $0.endedAt != nil
        }))
        return finished.max { ($0.endedAt ?? .distantPast, $0.id.uuidString) < ($1.endedAt ?? .distantPast, $1.id.uuidString) }
    }

    func lastPumpVolumeML() throws -> Double? {
        let key = activeRealm.encodedKey
        let measured = try context.fetch(FetchDescriptor<PumpEntry>(predicate: #Predicate {
            $0.realmKey == key && !$0.isTombstoned && $0.volumeML != nil
        }))
        return measured.max { $0.startedAt < $1.startedAt }?.volumeML
    }

    /// Starts this family's pumping session. Refused while one runs, on this
    /// phone or (once synced) the other; the server refuses a second one too.
    @discardableResult
    func startPump(side: PumpSide, at date: Date? = nil, expectedWriteContext: RealmWriteContext? = nil) throws -> PumpEntry {
        let expected = try expectedWriteContext ?? captureWriteContext()
        return try withRealmWrite(expected: expected) {
            guard try self.runningPump() == nil else { throw PumpError.alreadyRunning }
            let start = date ?? self.now
            try self.checkPumpTimes(start: start, end: nil)
            let pump = PumpEntry(startedAt: start, timeZoneID: TimeZone.current.identifier, side: side,
                                 createdBy: self.deviceID, realm: self.activeRealm)
            pump.lastModifiedAt = self.now
            self.context.insert(pump)
            try self.recordLocked(.create, on: pump)
            return pump
        }
    }

    /// Ends a running session now (or at `date`). A session forgotten past
    /// six hours ends at six: the longest the server keeps.
    @discardableResult
    func stopPump(_ pump: PumpEntry, at date: Date? = nil, expectedWriteContext: RealmWriteContext? = nil) throws -> Date {
        let expected = try expectedWriteContext ?? captureWriteContext()
        return try withRealmWrite(expected: expected) {
            guard pump.realmKey == expected.realm.encodedKey else { throw RealmWriteError.wrongRealm }
            guard pump.isRunning else { throw PumpError.notRunning }
            let cap = pump.startedAt.addingTimeInterval(PumpRules.maxSeconds)
            let end = max(pump.startedAt, min(date ?? self.now, cap))
            pump.endedAt = end
            pump.lastModifiedAt = self.now
            try self.recordLocked(.update, on: pump)
            return end
        }
    }

    func setPumpAmount(_ pump: PumpEntry, volumeML: Double?, expectedWriteContext: RealmWriteContext? = nil) throws {
        let expected = try expectedWriteContext ?? captureWriteContext()
        try withRealmWrite(expected: expected) {
            guard pump.realmKey == expected.realm.encodedKey else { throw RealmWriteError.wrongRealm }
            pump.volumeML = try Self.pumpVolume(volumeML)
            pump.lastModifiedAt = self.now
            try self.recordLocked(.update, on: pump)
        }
    }

    @discardableResult
    func logPump(side: PumpSide, from start: Date, to end: Date, volumeML: Double?, note: String?,
                 expectedWriteContext: RealmWriteContext? = nil) throws -> PumpEntry {
        let expected = try expectedWriteContext ?? captureWriteContext()
        return try withRealmWrite(expected: expected) {
            try self.checkPumpTimes(start: start, end: end)
            let amount = try Self.pumpVolume(volumeML)
            let pump = PumpEntry(startedAt: start, endedAt: end, timeZoneID: TimeZone.current.identifier, side: side,
                                 createdBy: self.deviceID, realm: self.activeRealm)
            pump.volumeML = amount
            pump.note = Self.trimmedPumpNote(note)
            pump.lastModifiedAt = self.now
            self.context.insert(pump)
            try self.recordLocked(.create, on: pump)
            return pump
        }
    }

    /// A finished session stays finished: clearing its end is refused, as
    /// the server refuses it (`pump_reopened`). A running one keeps running
    /// when `endedAt` is nil, with its Start and side corrected.
    func updatePump(_ pump: PumpEntry, side: PumpSide, startedAt: Date, endedAt: Date?, volumeML: Double?, note: String?,
                    expectedWriteContext: RealmWriteContext? = nil) throws {
        let expected = try expectedWriteContext ?? captureWriteContext()
        try withRealmWrite(expected: expected) {
            guard pump.realmKey == expected.realm.encodedKey else { throw RealmWriteError.wrongRealm }
            if pump.endedAt != nil, endedAt == nil { throw PumpError.invalidTimes }
            try self.checkPumpTimes(start: startedAt, end: endedAt)
            let amount = try Self.pumpVolume(volumeML)
            pump.side = side
            pump.startedAt = startedAt
            pump.endedAt = endedAt
            pump.volumeML = amount
            pump.note = Self.trimmedPumpNote(note)
            pump.lastModifiedAt = self.now
            try self.recordLocked(.update, on: pump)
        }
    }
}

extension BabyStore {
    /// The server's rules (`validatePumpTimes` plus the record rules' future
    /// check), so nothing is sent only to be refused and quarantined.
    func checkPumpTimes(start: Date, end: Date?) throws {
        let latest = now.addingTimeInterval(PumpRules.clockGrace)
        guard start <= latest else { throw PumpError.invalidTimes }
        guard let end else { return }
        guard end >= start, end <= latest, end.timeIntervalSince(start) <= PumpRules.maxSeconds else {
            throw PumpError.invalidTimes
        }
    }

    static func pumpVolume(_ ml: Double?) throws -> Double? {
        guard let ml else { return nil }
        let rounded = PumpRules.roundedVolume(ml)
        guard PumpRules.isValidVolume(rounded) else { throw PumpError.invalidVolume }
        return rounded
    }

    static func trimmedPumpNote(_ note: String?) -> String? {
        guard let trimmed = note?.trimmingCharacters(in: .whitespacesAndNewlines), !trimmed.isEmpty else { return nil }
        return trimmed
    }
}
```

```swift
    public static let removeAmount = LoggingL10n.text("Remove amount")
    public static let tooLong = LoggingL10n.text("A pumping session can be at most 6 hours.")
}

public enum PumpPanelMode: Equatable, Sendable {
    /// The Pump Home action: a side, then Start, now.
    case start
    /// Past entry → Pump: a finished session.
    case past
    /// History, the strip, or an Ask source: one session, running or not.
    case edit(UUID)
}

/// The pump panel, an interval activity in the entry-panel layout: side,
/// Start and End (End reads Running while live), the amount once it has
/// ended, and the note under Details.
///
/// Edit mode holds the session's id, not the session: the other phone may
/// stop or delete it while the panel is open. Every write fetches it afresh.
@MainActor @Observable
public final class PumpPanelModel {
    public let store: BabyStore
    public let mode: PumpPanelMode
    public let unit: VolumeUnit
    public var side: PumpSide = .both
    public var start: Date
    public var end: Date?
    public var hasAmount = false
    public var volumeML: Double = 0
    public var note = ""
    /// Start mode: the family's running pump, if any. The panel then offers
    /// only Edit running, whichever phone started it.
    public private(set) var runningPumpID: UUID?
    /// Edit mode: the session has no end yet.
    public private(set) var isRunning = false
    public private(set) var isGone = false
    public private(set) var latestAllowedDate: Date
    private let writeContext: RealmWriteContext?

    public init(store: BabyStore, mode: PumpPanelMode, unit: VolumeUnit = .millilitres) {
        self.store = store
        self.mode = mode
        self.unit = unit
        let now = store.now
        start = now
        latestAllowedDate = now
        writeContext = try? store.captureWriteContext()
        switch mode {
        case .start:
            runningPumpID = (try? store.runningPump())?.id
        case .past:
            start = now.addingTimeInterval(-20 * 60)
            end = now
        case .edit(let id):
            guard let pump = try? store.pump(id: id) else {
                isGone = true
                return
            }
            side = pump.side
            start = pump.startedAt
            end = pump.endedAt
            isRunning = pump.isRunning
            hasAmount = pump.volumeML != nil
            volumeML = pump.volumeML ?? 0
            note = pump.note ?? ""
            latestAllowedDate = max(now, pump.endedAt ?? pump.startedAt)
        }
    }

    public var isEditing: Bool {
        if case .edit = mode { return true }
        return false
    }

    /// The amount row shows once the session has ended.
    public var showsAmount: Bool { mode != .start && !isRunning }

    public var validationMessage: String? {
        guard mode != .start else { return nil }
        if let problem = TimeSpan(start: start, end: end).problem(latest: latestAllowedDate) {
            return TimeSpanCopy.message(problem)
        }
        if let end, end.timeIntervalSince(start) > PumpRules.maxSeconds { return PumpPanelCopy.tooLong }
        return nil
    }

    public var canSave: Bool {
        guard writeContext != nil, !isGone else { return false }
        if mode == .start { return runningPumpID == nil }
        guard validationMessage == nil, isRunning || end != nil else { return false }
        return !hasAmount || PumpRules.isValidVolume(PumpRules.roundedVolume(volumeML))
    }

    /// The panel's Start. Async so the Lock Screen card can start with it
    /// (Task 12).
    @discardableResult
    public func startNow() async throws -> PumpEntry {
        guard mode == .start, let writeContext else { throw EditModeError.invalid }
        let pump = try store.startPump(side: side, expectedWriteContext: writeContext)
        runningPumpID = pump.id
        return pump
    }

    public func save() throws {
        guard let writeContext else { throw EditModeError.invalid }
        let amount = hasAmount ? volumeML : nil
        switch mode {
        case .start:
            throw EditModeError.invalid
        case .past:
            guard let end, canSave else { throw EditModeError.invalid }
            try store.logPump(side: side, from: start, to: end, volumeML: amount, note: note, expectedWriteContext: writeContext)
        case .edit(let id):
            guard let pump = try store.pump(id: id) else {
                isGone = true
                throw EditModeError.gone
            }
            // Stopped on the other phone since the panel last looked: take
            // its end rather than send a running state for a finished session.
            if isRunning, !pump.isRunning { reload() }
            guard canSave else { throw EditModeError.invalid }
            try store.updatePump(pump, side: side, startedAt: start, endedAt: isRunning ? nil : end,
                                 volumeML: isRunning ? pump.volumeML : amount, note: note, expectedWriteContext: writeContext)
        }
    }

    public func delete() throws {
        guard case .edit(let id) = mode else { throw EditModeError.invalid }
        guard let pump = try store.pump(id: id) else {
            isGone = true
            throw EditModeError.gone
        }
        try store.softDelete(pump)
    }

    /// After any write, this phone's or the other's: a start made elsewhere
    /// turns Start into Edit running; a stop made elsewhere turns Running
    /// into the real End; a delete closes the panel.
    public func reload() {
        switch mode {
        case .start:
            runningPumpID = (try? store.runningPump())?.id
        case .past:
            break
        case .edit(let id):
            guard let pump = try? store.pump(id: id) else {
                isGone = true
                return
            }
            if isRunning, !pump.isRunning {
                isRunning = false
                end = pump.endedAt
                latestAllowedDate = max(store.now, pump.endedAt ?? pump.startedAt)
            }
        }
    }
}

                    .disabled(!model.canSave)
                    .accessibilityIdentifier("pump.startNow")
                }
            }
        }
        .editLifecycle(revision: model.store.revision, isGone: model.isGone, reload: model.reload, onGone: finish)
    }

    /// Start mode's action is Start, in the content: no footer.
    private var saveAction: (() -> Void)? {
        guard model.mode != .start else { return nil }
        return save
    }

    private var deleteAction: (() -> Void)? {
        guard model.isEditing else { return nil }
        return delete
    }

    private func start() {
        Task {
            do {
                try await model.startNow()
                errorReporter.clear()
                finish()
            } catch {
                // The other phone started one a moment ago: show Edit running.
                model.reload()
                errorReporter.report(ErrorBannerCopy.saveFailed(what: ErrorSubject.pump), error: error, category: AppLog.store)
            }
        }
    }

        if performEdit(model.save, failure: ErrorBannerCopy.saveFailed(what: ErrorSubject.pump), reporter: errorReporter) {
            finish()
        }
    }

    private func delete() {
        if performEdit(model.delete, failure: ErrorBannerCopy.deleteFailed(what: ErrorSubject.pump), reporter: errorReporter) {
            finish()
        }
    }

    private func finish() {
        guard !isFinished else { return }
        isFinished = true
        onDone()
    }
}
```

```swift
/// What the pump card shows. Platform-neutral so it is testable on macOS.
public struct PumpActivityContentState: Codable, Hashable, Sendable {
    public let startedAt: Date
    public let sideRaw: String

    public init(startedAt: Date, side: PumpSide) {
        self.startedAt = startedAt
        self.sideRaw = side.rawValue
    }

    public var side: PumpSide { PumpSide(rawValue: sideRaw) ?? .both }
    /// The card goes stale at the six-hour cap: no session runs past it.
    public var staleDate: Date { startedAt.addingTimeInterval(PumpRules.maxSeconds) }
}

public struct PumpCard: Equatable, Sendable {
    public let id: String
    public let pumpID: UUID
    public let state: PumpActivityContentState
}

/// The pump cards on this phone: ActivityKit on iOS, memory in tests.
public protocol PumpCardBoard: Sendable {
    func cards() -> [PumpCard]
    func request(pumpID: UUID, state: PumpActivityContentState) throws -> String?
    func update(id: String, state: PumpActivityContentState) async
    func end(id: String) async
}

public final class MemoryPumpCardBoard: PumpCardBoard, @unchecked Sendable {
    private let lock = NSLock()
    private var stored: [PumpCard] = []
    private var endedIDs: [String] = []

    public init() {}

    public var ended: [String] { lock.withLock { endedIDs } }
    public func cards() -> [PumpCard] { lock.withLock { stored } }

    public func request(pumpID: UUID, state: PumpActivityContentState) throws -> String? {
        lock.withLock {
            let id = UUID().uuidString
            stored.append(PumpCard(id: id, pumpID: pumpID, state: state))
            return id
        }
    }

    public func update(id: String, state: PumpActivityContentState) async {
        lock.withLock {
            guard let index = stored.firstIndex(where: { $0.id == id }) else { return }
            stored[index] = PumpCard(id: id, pumpID: stored[index].pumpID, state: state)
        }
    }

    public func end(id: String) async {
        lock.withLock {
            stored.removeAll { $0.id == id }
            endedIDs.append(id)
        }
    }
}

struct NoPumpCardBoard: PumpCardBoard {
    func cards() -> [PumpCard] { [] }
    func request(pumpID: UUID, state: PumpActivityContentState) throws -> String? { nil }
    func update(id: String, state: PumpActivityContentState) async {}
    func end(id: String) async {}
}

/// The pumping card on the phone that started the session, separate from the
/// feed and sleep cards so a bottle card and a pump card sit side by side.
/// The other phone gets none: that needs server push, which Part 1 leaves
/// out.
@MainActor
public enum PumpActivityController {
    public enum Decision: Equatable, Sendable { case keep, update(PumpActivityContentState), end }

    /// Starts the card for a pump this phone just started. Never called for
    /// one a sync brought in.
    public static func start(for pump: PumpEntry) async {
        let board = PumpCards.board
        for card in board.cards() where card.pumpID != pump.id {
            await board.end(id: card.id)
        }
        guard !board.cards().contains(where: { $0.pumpID == pump.id }) else { return }
        _ = try? board.request(pumpID: pump.id, state: PumpActivityContentState(startedAt: pump.startedAt, side: pump.side))
    }

    /// A card stays only while its own session runs and is under six hours;
    /// an edit of that session (side, start) is carried over.
    public nonisolated static func decision(for card: PumpCard, runningID: UUID?,
                                            runningState: PumpActivityContentState?, now: Date) -> Decision {
        guard let runningID, let runningState, runningID == card.pumpID, now < runningState.staleDate else { return .end }
        return runningState == card.state ? .keep : .update(runningState)
    }

    /// Ends every card whose session is over, here or on the other phone, was
    /// superseded, or is past six hours. Runs at launch, on activation and on
    /// every store change, so a stop that arrives by sync takes the card
    /// down. Never starts one.
    public static func reconcile(in store: BabyStore) async {
        let board = PumpCards.board
        let running = try? store.runningPump()
        let state = running.map { PumpActivityContentState(startedAt: $0.startedAt, side: $0.side) }
        for card in board.cards() {
            switch decision(for: card, runningID: running?.id, runningState: state, now: store.now) {
            case .keep: break
            case .update(let next): await board.update(id: card.id, state: next)
            case .end: await board.end(id: card.id)
            }
        }
    }
}
```
