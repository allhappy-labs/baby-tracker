# Pumping Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A parent can time a pumping session (Left / Right / Both), stop it, give it an amount, and see it on every baby's Home, History and Ask on both phones, while a bottle or sleep timer runs alongside, untouched.

**Architecture:**
- **One new synced kind, `pump`, owned by the family.** It has no `baby_id`. The server keeps it in `pump_entries` (migration 000030). The phone keeps it as a SwiftData `PumpEntry` in `SchemaV11`.
- **A running pump is an ordinary entry with no end.** It is not an `ActiveTimer`.
  - On the server, a partial unique index allows one open pump per family.
  - Under the family lock, a pre-check turns a second open start into `superseded` / `pump_running`. A duplicate timer start is refused the same way, by its own pre-check.
- **Per-baby screens merge the realm's pumps.** History, Home's Today card and Ask all read `entries(for: babyID…)` and `homeSnapshot(for:)`; both include the realm's pumps. Insights skips them.
- **The UI reuses the entry-panel parts.** The pump panel is built from `EntryPanel`, `TimeSpanSection` (gaining an `.running` end style), `DetailsSection` and `BottleVolumeField`. A separate `PumpStripView` sits above Home's dock. A separate `PumpActivityAttributes` Live Activity lives on the phone that started the session.

**Tech Stack:**
- Swift 6.2, SwiftUI, SwiftData (iOS 26), Swift Testing, ActivityKit, App Intents, XCUITest.
- Go server with PostgreSQL migrations.

**Spec:** `docs/superpowers/specs/2026-10-09-pumping-design.md`

## Global Constraints

- **Branch:** work in the worktree `.worktrees/pumping` on branch `feat/pumping`, never directly on `main`. Other sessions commit to `main` in parallel. Use `/usr/bin/git` inside the worktree; RTK's git rewrite trips the worktree guard.
- **Server migration:** `000030_pumping.sql`. The compatibility window moves to `min 30, max 30`.
- **Wire kind:** `pump`, payload version **1**, operations `create`, `update`, `delete`.
  - Payload keys: `started_at`, `ended_at`, `time_zone_id`, `side`, `volume_ml`, `note`. `ended_at`, `volume_ml` and `note` are always present and may be `null`.
  - A pump delete payload is `{}`. There is never a `baby_id`.
- **Validation (server, mirrored on the phone):**
  - `side` is one of `left|right|both`.
  - `volume_ml` is 0–1000 with at most 2 decimals.
  - `ended_at` is not before `started_at`, and a session lasts at most 6 h.
  - `started_at` and `ended_at` are not later than the server's accept time plus 1 minute. This is the same grace the timer edit rule uses (`timers.go`: "A minute of grace for a phone clock running ahead").
- **One running pump per family:**
  - unique partial index `(family_id) WHERE ended_at IS NULL AND tombstoned_at IS NULL`;
  - the losing open start gets `status: "superseded", code: "pump_running"`, with the running pump as `canonical_entity`.
- **Ownership:**
  - `PumpEntry` conforms to `ChangeLoggable`, `Touchable` and `RealmScoped`. It must **not** conform to `BabyOwnedRecord`.
  - The child-delete cascade never touches `pump_entries`.
- **Unchanged:** feed and sleep timer behaviour, `ActiveTimer`, `TimerActivityAttributes`, `TimerKind` and the feed Live Activity. Insights shows no pumps.
- **SwiftData:**
  - Add `SchemaV11` = `SchemaV10.models + [PumpEntry.self]`.
  - Add one lightweight stage V10→V11. No V10 model changes, so nothing needs freezing.
  - A V10 store must open **in place**, not be moved aside.
- **Copy:** every new user-facing string goes into the target's `Localizable.xcstrings` with `de`, `es`, `fr`, `it` and `uk` values via `scripts/add-catalog-strings.py`. `en` is the source language. It must fit Ukrainian at the largest accessibility size; Task 11 checks this.
- **Ask:** no new tool, no keyword routing, no validators. `pump` only joins the kinds the existing reads accept; the model picks the read. This is a user rule.
- **Simulator:** only the shared device `platform=iOS Simulator,id=D17101C9-01EB-488D-AFE1-58E6C089B853`. Run `pgrep xcodebuild` first and never run two xcodebuild jobs at once. Never create or clone a simulator.
- **UI tests:** run only the classes a task names, with `-only-testing:`. Assert logic and identifiers, never layout geometry.
- **Test count:** `make test` asserts a literal total (`EXPECTED_TESTS` in `Makefile`, 1700 at plan time).
  - Every task that adds or removes Swift tests sets it, in the same commit, to the total `make test` reports.
  - The commit message says `(+N tests)`.
  - A parameterized test counts each argument.
- **Deploy order:** server first (schema 30 live), then merge to `main`, then the phones. A schema-29 server answers a `pump` mutation with `invalid_request`, and the client quarantines it for good. Deploying needs the user's approval.

## Review Focus

These are the five ways this is most likely to hurt a real family. The test that pins each one is in the task named.

1. **Both phones start a pump while one is offline.** After sync there is exactly one running pump. If the losing phone has already stopped its session, the session still reaches the family as a finished entry. If its session is still running, it gives way to the winner. *Task 2, `TestSecondOpenPumpIsSupersededAndAFinishedOneIsNot`; Task 3, `aLosingStartAlreadyStoppedIsSentAgainFinished` and `aLosingStartStillRunningGivesWayToTheWinner`.*
2. **A pump is forgotten and stopped 7 hours later** (strip, panel or Lock Screen). It saves ending exactly 6 h after its start and is never refused by the server. *Task 4, `stoppingPastSixHoursEndsAtTheCap`; Task 9, `stoppingFromTheCardAsksForTheAmountNextOpen`.*
3. **An ounces user enters 3 oz.** The amount is stored as 88.72 ml, rounded to 2 decimals, so the server accepts it. A third decimal is refused by the server. *Task 4, `anOunceAmountIsStoredToTwoDecimals`; Task 1, `TestPumpValidation` (`"3 places"`).*
4. **The owner logged pumps before creating the family.** They reach the caregiver. The import manifest, which keys records by baby, neither drops them nor gets them refused. *Task 3, `importSendsPumpsAsPlainCreates`; Task 11, the E2E step "pump logged before the family".*
5. **The other phone stops or deletes the session, or it passes 6 h.** This phone's Lock Screen card ends at the next store change or app activation, and never shows a running clock for a session that is over. *Task 9, `aCardWhosePumpEndedElsewhereEnds` and `aCardPastTheSixHourCapEnds`.*

```go
// validatePumpTimes: a pumping session's end, when it has one, is not before
// its start and at most six hours after it. Whether either is in the future
// needs the accept time, so Apply checks that.
func validatePumpTimes(start string, end *string) error {
	startNormalized, err := protocol.NormalizeTimestamp(start)
	if err != nil {
		return protocol.ErrInvalidTimestamp
	}
	if end == nil {
		return nil
	}
	endNormalized, err := protocol.NormalizeTimestamp(*end)
	if err != nil {
		return protocol.ErrInvalidTimestamp
	}
	startTime, _ := time.Parse("2006-01-02T15:04:05.000000Z", startNormalized)
	endTime, _ := time.Parse("2006-01-02T15:04:05.000000Z", endNormalized)
	if endTime.Before(startTime) || endTime.Sub(startTime) > 6*time.Hour {
		return protocol.ErrInvalidTimestamp
	}
	return nil
}
```

```sql
    id uuid NOT NULL CHECK (id <> '00000000-0000-0000-0000-000000000000'),
    entity_version bigint NOT NULL CHECK (entity_version BETWEEN 1 AND 9007199254740991),
```

```go
func (r *Repository) GetPump(ctx context.Context, tx pgx.Tx, familyID, id string) (protocol.PumpPayload, protocol.EntityMeta, error) {
	var p protocol.PumpPayload
	var m protocol.EntityMeta
	var tomb, volume *string
	err := tx.QueryRow(ctx, `SELECT id::text,family_id::text,entity_version,creator_account_id::text,last_editor_account_id::text,
	to_char(client_mutation_time AT TIME ZONE 'UTC','YYYY-MM-DD"T"HH24:MI:SS.US"Z"'),to_char(accepted_at AT TIME ZONE 'UTC','YYYY-MM-DD"T"HH24:MI:SS.US"Z"'),
	CASE WHEN tombstoned_at IS NULL THEN NULL ELSE to_char(tombstoned_at AT TIME ZONE 'UTC','YYYY-MM-DD"T"HH24:MI:SS.US"Z"') END,
	to_char(started_at AT TIME ZONE 'UTC','YYYY-MM-DD"T"HH24:MI:SS.US"Z"'),
	CASE WHEN ended_at IS NULL THEN NULL ELSE to_char(ended_at AT TIME ZONE 'UTC','YYYY-MM-DD"T"HH24:MI:SS.US"Z"') END,
	time_zone_id,side,volume_ml::text,note
	FROM pump_entries WHERE family_id=$1 AND id=$2`, familyID, id).Scan(&m.ID, &m.FamilyID, &m.EntityVersion, &m.CreatorAccountID,
		&m.LastEditorAccountID, &m.ClientMutationTime, &m.AcceptedAt, &tomb, &p.StartedAt, &p.EndedAt, &p.TimeZoneID, &p.Side, &volume, &p.Note)
	if errors.Is(err, pgx.ErrNoRows) {
		return p, m, ErrNotFound
	}
	m.TombstonedAt = tomb
	if err != nil {
		return p, m, err
	}
	if volume != nil {
		p.VolumeML, err = protocol.ParseDecimal(*volume)
	}
	return p, m, err
}

func (r *Repository) putPump(ctx context.Context, tx pgx.Tx, m protocol.EntityMeta, p protocol.PumpPayload, b int64) (protocol.CanonicalEntity, error) {
	result, err := tx.Exec(ctx, `INSERT INTO pump_entries(family_id,id,entity_version,creator_account_id,last_editor_account_id,client_mutation_time,accepted_at,tombstoned_at,last_sequence,storage_bytes,started_at,ended_at,time_zone_id,side,volume_ml,note)
	VALUES($1,$2,$3,$4,$5,$6,$7,$8,0,$9,$10,$11,$12,$13,$14,$15) ON CONFLICT(family_id,id) DO UPDATE SET entity_version=EXCLUDED.entity_version,last_editor_account_id=EXCLUDED.last_editor_account_id,client_mutation_time=EXCLUDED.client_mutation_time,accepted_at=EXCLUDED.accepted_at,tombstoned_at=EXCLUDED.tombstoned_at,last_sequence=0,storage_bytes=EXCLUDED.storage_bytes,started_at=EXCLUDED.started_at,ended_at=EXCLUDED.ended_at,time_zone_id=EXCLUDED.time_zone_id,side=EXCLUDED.side,volume_ml=EXCLUDED.volume_ml,note=EXCLUDED.note`,
		m.FamilyID, m.ID, m.EntityVersion, m.CreatorAccountID, m.LastEditorAccountID, m.ClientMutationTime, m.AcceptedAt, m.TombstonedAt, b,
		p.StartedAt, p.EndedAt, p.TimeZoneID, p.Side, decimalSQL(p.VolumeML), p.Note)
	if err == nil && result.RowsAffected() != 1 {
		err = protocol.ErrInvalidMutation
	}
	return protocol.CanonicalEntity{EntityKind: "pump", Meta: m, Payload: p}, err
}

// findOpenPump is the family's running pump other than excludingID, or
// ErrNotFound. Apply calls it under the family lock, so it cannot race.
func (r *Repository) findOpenPump(ctx context.Context, tx pgx.Tx, familyID, excludingID string) (protocol.CanonicalEntity, error) {
	var id string
	err := tx.QueryRow(ctx, `SELECT id::text FROM pump_entries WHERE family_id=$1 AND id<>$2 AND ended_at IS NULL AND tombstoned_at IS NULL`,
		familyID, excludingID).Scan(&id)
	if errors.Is(err, pgx.ErrNoRows) {
		return protocol.CanonicalEntity{}, ErrNotFound
	}
	if err != nil {
		return protocol.CanonicalEntity{}, err
	}
	return r.get(ctx, tx, "pump", familyID, id)
}
```

```swift
import Foundation
import SwiftData
import BabyCore

public enum PumpError: Error, Equatable, Sendable {
    /// A pump is already running in this family.
    case alreadyRunning
    /// End before start, longer than six hours, or later than now.
    case invalidTimes
    /// Outside 0–1000 ml.
    case invalidVolume
    /// Stop asked of a session that has already ended.
    case notRunning
}

public extension BabyStore {
    func runningPump() throws -> PumpEntry? {
        let key = activeRealm.encodedKey
        var descriptor = FetchDescriptor<PumpEntry>(predicate: #Predicate {
            $0.realmKey == key && !$0.isTombstoned && $0.endedAt == nil
        })
        descriptor.sortBy = [SortDescriptor(\.startedAt, order: .reverse)]
        return try context.fetch(descriptor).first
    }

    func pump(id: UUID) throws -> PumpEntry? {
        let key = activeRealm.encodedKey
        return try context.fetch(FetchDescriptor<PumpEntry>(predicate: #Predicate {
            $0.id == id && $0.realmKey == key && !$0.isTombstoned
        })).first
    }

    func pumps(from start: Date, to end: Date) throws -> [PumpEntry] {
        let key = activeRealm.encodedKey
        var descriptor = FetchDescriptor<PumpEntry>(predicate: #Predicate {
            $0.realmKey == key && !$0.isTombstoned && $0.startedAt >= start && $0.startedAt < end
        })
        descriptor.sortBy = [SortDescriptor(\.startedAt, order: .reverse)]
        return try context.fetch(descriptor)
    }

    func lastFinishedPump() throws -> PumpEntry? {
        let key = activeRealm.encodedKey
        let finished = try context.fetch(FetchDescriptor<PumpEntry>(predicate: #Predicate {
            $0.realmKey == key && !$0.isTombstoned && $0.endedAt != nil
        }))
        return finished.max { ($0.endedAt ?? .distantPast, $0.id.uuidString) < ($1.endedAt ?? .distantPast, $1.id.uuidString) }
    }

    func lastPumpVolumeML() throws -> Double? {
        let key = activeRealm.encodedKey
        let measured = try context.fetch(FetchDescriptor<PumpEntry>(predicate: #Predicate {
            $0.realmKey == key && !$0.isTombstoned && $0.volumeML != nil
        }))
        return measured.max { $0.startedAt < $1.startedAt }?.volumeML
    }

    /// Starts this family's pumping session. Refused while one runs, on this
    /// phone or (once synced) the other; the server refuses a second one too.
    @discardableResult
    func startPump(side: PumpSide, at date: Date? = nil, expectedWriteContext: RealmWriteContext? = nil) throws -> PumpEntry {
        let expected = try expectedWriteContext ?? captureWriteContext()
        return try withRealmWrite(expected: expected) {
            guard try self.runningPump() == nil else { throw PumpError.alreadyRunning }
            let start = date ?? self.now
            try self.checkPumpTimes(start: start, end: nil)
            let pump = PumpEntry(startedAt: start, timeZoneID: TimeZone.current.identifier, side: side,
                                 createdBy: self.deviceID, realm: self.activeRealm)
            pump.lastModifiedAt = self.now
            self.context.insert(pump)
            try self.recordLocked(.create, on: pump)
            return pump
        }
    }

    /// Ends a running session now (or at `date`). A session forgotten past
    /// six hours ends at six: the longest the server keeps.
    @discardableResult
    func stopPump(_ pump: PumpEntry, at date: Date? = nil, expectedWriteContext: RealmWriteContext? = nil) throws -> Date {
        let expected = try expectedWriteContext ?? captureWriteContext()
        return try withRealmWrite(expected: expected) {
            guard pump.realmKey == expected.realm.encodedKey else { throw RealmWriteError.wrongRealm }
            guard pump.isRunning else { throw PumpError.notRunning }
            let cap = pump.startedAt.addingTimeInterval(PumpRules.maxSeconds)
            let end = max(pump.startedAt, min(date ?? self.now, cap))
            pump.endedAt = end
            pump.lastModifiedAt = self.now
            try self.recordLocked(.update, on: pump)
            return end
        }
    }

    func setPumpAmount(_ pump: PumpEntry, volumeML: Double?, expectedWriteContext: RealmWriteContext? = nil) throws {
        let expected = try expectedWriteContext ?? captureWriteContext()
        try withRealmWrite(expected: expected) {
            guard pump.realmKey == expected.realm.encodedKey else { throw RealmWriteError.wrongRealm }
            pump.volumeML = try Self.pumpVolume(volumeML)
            pump.lastModifiedAt = self.now
            try self.recordLocked(.update, on: pump)
        }
    }

    @discardableResult
    func logPump(side: PumpSide, from start: Date, to end: Date, volumeML: Double?, note: String?,
                 expectedWriteContext: RealmWriteContext? = nil) throws -> PumpEntry {
        let expected = try expectedWriteContext ?? captureWriteContext()
        return try withRealmWrite(expected: expected) {
            try self.checkPumpTimes(start: start, end: end)
            let pump = PumpEntry(startedAt: start, endedAt: end, timeZoneID: TimeZone.current.identifier, side: side,
                                 createdBy: self.deviceID, realm: self.activeRealm)
            pump.volumeML = try Self.pumpVolume(volumeML)
            pump.note = Self.trimmedPumpNote(note)
            pump.lastModifiedAt = self.now
            self.context.insert(pump)
            try self.recordLocked(.create, on: pump)
            return pump
        }
    }

    /// A finished session stays finished: clearing its end is refused, as
    /// the server refuses it (`pump_reopened`).
    func updatePump(_ pump: PumpEntry, side: PumpSide, startedAt: Date, endedAt: Date?, volumeML: Double?, note: String?,
                    expectedWriteContext: RealmWriteContext? = nil) throws {
        let expected = try expectedWriteContext ?? captureWriteContext()
        try withRealmWrite(expected: expected) {
            guard pump.realmKey == expected.realm.encodedKey else { throw RealmWriteError.wrongRealm }
            if pump.endedAt != nil, endedAt == nil { throw PumpError.invalidTimes }
            try self.checkPumpTimes(start: startedAt, end: endedAt)
            pump.side = side
            pump.startedAt = startedAt
            pump.endedAt = endedAt
            pump.volumeML = try Self.pumpVolume(volumeML)
            pump.note = Self.trimmedPumpNote(note)
            pump.lastModifiedAt = self.now
            try self.recordLocked(.update, on: pump)
        }
    }
}

extension BabyStore {
    /// The server's rules (`validatePumpTimes` plus Apply's future check),
    /// so nothing is sent only to be refused and quarantined.
    func checkPumpTimes(start: Date, end: Date?) throws {
        let latest = now.addingTimeInterval(PumpRules.clockGrace)
        guard start <= latest else { throw PumpError.invalidTimes }
        guard let end else { return }
        guard end >= start, end <= latest, end.timeIntervalSince(start) <= PumpRules.maxSeconds else {
            throw PumpError.invalidTimes
        }
    }

    static func pumpVolume(_ ml: Double?) throws -> Double? {
        guard let ml else { return nil }
        let rounded = PumpRules.roundedVolume(ml)
        guard PumpRules.isValidVolume(rounded) else { throw PumpError.invalidVolume }
        return rounded
    }

    static func trimmedPumpNote(_ note: String?) -> String? {
        guard let trimmed = note?.trimmingCharacters(in: .whitespacesAndNewlines), !trimmed.isEmpty else { return nil }
        return trimmed
    }
}
```

```swift
public enum PumpPanelMode: Equatable, Sendable {
    /// More → Pump: a side, then Start, now.
    case start
    /// Past entry → Pump: a finished session.

    case edit(UUID)

/// The pump panel, an interval activity in the entry-panel layout: side,
/// Start and End (End reads Running while live), the amount once it has
/// ended, and the note under Details.
///
/// Edit mode holds the session's id, not the session: the other phone may
/// stop or delete it while the panel is open. Every write fetches it afresh.
@MainActor @Observable
public final class PumpPanelModel {
    public let store: BabyStore
    public let mode: PumpPanelMode
    public let unit: VolumeUnit
    public var side: PumpSide = .both
    public var start: Date
    public var end: Date?
    public var hasAmount = false
    public var volumeML: Double = 0
    public var note = ""
    /// Start mode: the family's running pump, if any. The panel then offers
    /// only Edit running, whichever phone started it.
    public private(set) var runningPumpID: UUID?
    /// Edit mode: the session has no end yet.
    public private(set) var isRunning = false
    public private(set) var isGone = false
    public private(set) var latestAllowedDate: Date
    private let writeContext: RealmWriteContext?

    public init(store: BabyStore, mode: PumpPanelMode, unit: VolumeUnit = .millilitres) {
        self.store = store
        self.mode = mode
        self.unit = unit
        let now = store.now
        start = now
        latestAllowedDate = now
        writeContext = try? store.captureWriteContext()
        switch mode {
        case .start:
            runningPumpID = try? store.runningPump()?.id
        case .past:
            start = now.addingTimeInterval(-20 * 60)
            end = now
        case .edit(let id):
            guard let pump = try? store.pump(id: id) else {
                isGone = true
                return
            }
            side = pump.side
            start = pump.startedAt
            end = pump.endedAt
            isRunning = pump.isRunning
            hasAmount = pump.volumeML != nil
            volumeML = pump.volumeML ?? 0
            note = pump.note ?? ""
            latestAllowedDate = max(now, pump.endedAt ?? pump.startedAt)
        }
    }

    public var isEditing: Bool { if case .edit = mode { true } else { false } }

    /// The amount row shows once the session has ended.
    public var showsAmount: Bool { mode != .start && !isRunning }

    public var validationMessage: String? {
        guard mode != .start else { return nil }
        if let problem = TimeSpan(start: start, end: end).problem(latest: latestAllowedDate) {
            return TimeSpanCopy.message(problem)
        }
        if let end, end.timeIntervalSince(start) > PumpRules.maxSeconds { return PumpPanelCopy.tooLong }
        return nil
    }

    public var canSave: Bool {
        guard writeContext != nil, !isGone else { return false }
        if mode == .start { return runningPumpID == nil }
        guard validationMessage == nil, isRunning || end != nil else { return false }
        return !hasAmount || PumpRules.isValidVolume(PumpRules.roundedVolume(volumeML))
    }

    /// More → Pump's Start. Async so the Lock Screen card can start with it.
    @discardableResult
    public func startNow() async throws -> PumpEntry {
        guard mode == .start, let writeContext else { throw EditModeError.invalid }
        let pump = try store.startPump(side: side, expectedWriteContext: writeContext)
        runningPumpID = pump.id
        return pump
    }

    public func save() throws {
        guard let writeContext else { throw EditModeError.invalid }
        let amount = hasAmount ? volumeML : nil
        switch mode {
        case .start:
            throw EditModeError.invalid
        case .past:
            guard let end, canSave else { throw EditModeError.invalid }
            try store.logPump(side: side, from: start, to: end, volumeML: amount, note: note, expectedWriteContext: writeContext)
        case .edit(let id):
            guard let pump = try store.pump(id: id) else {
                isGone = true
                throw EditModeError.gone
            }
            guard canSave else { throw EditModeError.invalid }
            try store.updatePump(pump, side: side, startedAt: start, endedAt: isRunning ? nil : end,
                                 volumeML: isRunning ? pump.volumeML : amount, note: note, expectedWriteContext: writeContext)
        }
    }

    public func delete() throws {
        guard case .edit(let id) = mode else { throw EditModeError.invalid }
        guard let pump = try store.pump(id: id) else {
            isGone = true
            throw EditModeError.gone
        }
        try store.softDelete(pump)
    }

    /// After any write, this phone's or the other's: a stop made elsewhere
    /// turns Running into the real End; a delete closes the panel.
    public func reload() {
        switch mode {
        case .start:
            runningPumpID = try? store.runningPump()?.id
        case .past:
            break
        case .edit(let id):
            guard let pump = try? store.pump(id: id) else {
                isGone = true
                return
            }
            if isRunning, !pump.isRunning {
                isRunning = false
                end = pump.endedAt
                latestAllowedDate = max(store.now, pump.endedAt ?? pump.startedAt)
            }
        }
    }
}

                                .buttonStyle(.primaryFill(minHeight: 56))
                                .disabled(!model.canSave)
                                .accessibilityIdentifier("pump.startNow")
                        }
                    }
                }
            }

        Task {
            do {
                try await model.startNow()
                errorReporter.clear()
                finish()
            } catch {
                errorReporter.report(ErrorBannerCopy.saveFailed(what: ErrorSubject.pump), error: error, category: AppLog.store)
            }
        }
    }

    private func save() {
        if performEdit(model.save, failure: ErrorBannerCopy.saveFailed(what: ErrorSubject.pump), reporter: errorReporter) {
            finish()
        }
    }

    private func delete() {
        if performEdit(model.delete, failure: ErrorBannerCopy.deleteFailed(what: ErrorSubject.pump), reporter: errorReporter) {
            finish()
        }
    }

    private func finish() {
        guard !isFinished else { return }
        isFinished = true
        onDone()
    }
```

```swift
/// What the pump card shows. Platform-neutral so it is testable on macOS.
public struct PumpActivityContentState: Codable, Hashable, Sendable {
    public let startedAt: Date
    public let sideRaw: String

    public init(startedAt: Date, side: PumpSide) {
        self.startedAt = startedAt
        self.sideRaw = side.rawValue
    }

    public var side: PumpSide { PumpSide(rawValue: sideRaw) ?? .both }
    /// The card goes stale at the six-hour cap: no session runs past it.
    public var staleDate: Date { startedAt.addingTimeInterval(PumpRules.maxSeconds) }
}

public struct PumpCard: Equatable, Sendable {
    public let id: String
    public let pumpID: UUID
    public let state: PumpActivityContentState
}

/// The pump cards on this phone: ActivityKit on iOS, memory in tests.
public protocol PumpCardBoard: Sendable {
    func cards() -> [PumpCard]
    func request(pumpID: UUID, state: PumpActivityContentState) throws -> String?
    func update(id: String, state: PumpActivityContentState) async
    func end(id: String) async
}

public final class MemoryPumpCardBoard: PumpCardBoard, @unchecked Sendable {
    private let lock = NSLock()
    private var stored: [PumpCard] = []
    private var endedIDs: [String] = []

    public init() {}

    public var ended: [String] { lock.withLock { endedIDs } }
    public func cards() -> [PumpCard] { lock.withLock { stored } }

    public func request(pumpID: UUID, state: PumpActivityContentState) throws -> String? {
        lock.withLock {
            let id = UUID().uuidString
            stored.append(PumpCard(id: id, pumpID: pumpID, state: state))
            return id
        }
    }

    public func update(id: String, state: PumpActivityContentState) async {
        lock.withLock {
            guard let index = stored.firstIndex(where: { $0.id == id }) else { return }
            stored[index] = PumpCard(id: id, pumpID: stored[index].pumpID, state: state)
        }
    }

    public func end(id: String) async {
        lock.withLock {
            stored.removeAll { $0.id == id }
            endedIDs.append(id)
        }
    }
}

struct NoPumpCardBoard: PumpCardBoard {
    func cards() -> [PumpCard] { [] }
    func request(pumpID: UUID, state: PumpActivityContentState) throws -> String? { nil }
    func update(id: String, state: PumpActivityContentState) async {}
    func end(id: String) async {}
}

/// The pumping card on the phone that started the session, separate from the
/// feed and sleep cards so a bottle card and a pump card sit side by side.
/// The other phone gets none: that needs server push, which Part 1 leaves
/// out.
@MainActor
public enum PumpActivityController {
    public enum Decision: Equatable, Sendable { case keep, update(PumpActivityContentState), end }

    /// Starts the card for a pump this phone just started. Never called for
    /// one a sync brought in.
    public static func start(for pump: PumpEntry) async {
        let board = PumpCards.board
        for card in board.cards() where card.pumpID != pump.id {
            await board.end(id: card.id)
        }
        guard !board.cards().contains(where: { $0.pumpID == pump.id }) else { return }
        _ = try? board.request(pumpID: pump.id, state: PumpActivityContentState(startedAt: pump.startedAt, side: pump.side))
    }

    /// A card stays only while its own session runs and is under six hours;
    /// an edit of that session (side, start) is carried over.
    public nonisolated static func decision(for card: PumpCard, runningID: UUID?,
                                            runningState: PumpActivityContentState?, now: Date) -> Decision {
        guard let runningID, let runningState, runningID == card.pumpID, now < runningState.staleDate else { return .end }
        return runningState == card.state ? .keep : .update(runningState)
    }

    /// Ends every card whose session is over, here or on the other phone, or
    /// past six hours. Runs at launch, on activation and on every store
    /// change, so a stop that arrives by sync takes the card down. Never
    /// starts one.
    public static func reconcile(in store: BabyStore) async {
        let board = PumpCards.board
        let running = try? store.runningPump()
        let state = running.map { PumpActivityContentState(startedAt: $0.startedAt, side: $0.side) }
        for card in board.cards() {
            switch decision(for: card, runningID: running?.id, runningState: state, now: store.now) {
            case .keep: break
            case .update(let next): await board.update(id: card.id, state: next)
            case .end: await board.end(id: card.id)
            }
        }
    }
}
```

```swift
    /// its Stop; the strip's Stop asks How much?; Save; History lists it.
    func testAPumpBesideARunningBottleFromStartToHistory() {
        let app = Harness.launch(Harness.Launch(reset: true, seedBaby: true, runningBottle: true))
        XCTAssertTrue(app.buttons["home.stop"].waitForExistence(timeout: 60), "the running bottle did not show")
```
